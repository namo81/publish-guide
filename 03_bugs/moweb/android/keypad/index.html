keypad On/Off 에 따른 viewport 높이 조정

상세 현상

chrome 에서 모바일 화면 확인 시, input focus 로 keypad 가 올라올 때, viewport 높이가 변하지 않아 keypad 가 화면을 덮음.

이는 chrome 업데이트 과정에서 chrome 108+ 이상 버전에서 viewport 높이가 변하지 않고, keypad 가 덮는 형식으로 변경됨.

해결 방법

메타태그 (viewport) 에 interactive-widget=resizes-content 속성을 추가하면 viewport 높이가 변경됨.

<meta name="viewport" content="user-scalable=yes, initial-scale=1.0, maximum-scale=5.0, minimum-scale=1.0, width=device-width, interactive-widget=resizes-content">
