Select 디자인 적용

option 까지 모두 디자인을 적용하는 경우 사용.

단, 추가적인 항목은 불가하며, select 의 value / text 값만 사용 가능.

<div class="n-select">
	<select name="" title="">
		<option value="">직접 선택</option>
		<option value="">nate.com</option>
		<option value="">daum.net</option>
	</select>
</div>
