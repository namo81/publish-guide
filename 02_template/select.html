Select 디자인 적용

option 까지 모두 디자인을 적용하는 경우 사용.

단, 추가적인 항목은 불가하며, select 의 value / text 값만 사용 가능.

  • - hidden option 은 목록에서 제외 (placeholder 용도 - 선택 전 상태는 영역에 'not-sel' 클래스) / disabled option 은 선택 불가
  • - option 의 class 는 목록 버튼에 추가됨
  • - select 에 연결된 label 이 있으면 버튼에 "label + 선택값" 으로 연결 / select 에 'readonly' 클래스 시 선택 불가
  • - 키보드 : 방향키(닫힌 상태에서 열기 / 항목 이동), Enter(선택), ESC · Tab(닫기)
  • - 값이 바뀐 경우에만 select 에 change 이벤트 발생 / 스크립트로 selectedIndex 변경 후 change 이벤트를 dispatch 하면 버튼 텍스트 갱신
<label for="sel-mail">이메일 도메인</label>
<div class="n-select">
	<select name="sel-mail" id="sel-mail">
		<option value="" hidden>선택해주세요</option>
		<option value="direct">직접 입력</option>
		<option value="nate" disabled>nate.com</option>
		<option value="google">google.com</option>
	</select>
</div>

selectName.selectDisable(true);	// 사용 불가 설정

// 동일 클래스 다수 설정 (nSelArr 에 저장 - 1개일 경우 객체 / 다수일 경우 배열)
n_selects('.n-select');

// 스크립트로 값 변경 시
selectName.select.selectedIndex = 2;
selectName.select.dispatchEvent(new Event('change'));

dropdown 방식

UI 는 select 형태이나 기능이 다른 경우 사용

ex. input 리스트를 토글하여 다중 선택 및 선택값 표출 등

** 체크박스 다중 선택 + 확인 / 취소 기능

html / css 구조는 유지하며, 타 기능 적용 시 script 수정 필요

  • - 확인 버튼 : 'btn-confirm' 클래스 (없을 경우 목록 내 첫 번째 '.btn') - 선택 항목을 버튼에 표시 (1개 : 항목명 / 다수 : 'OO 외 n개' / 전체 : '전체')
  • - 취소 버튼 : 'btn-cancel' 클래스 (선택) - 열기 전 체크 상태로 복원
  • - 외부 클릭 / ESC / 키보드로 영역 밖 이동 시 취소와 동일하게 처리
  • - 확인 시 영역(.n-select)에 change 이벤트 발생 / 선언변수.getChecked() : 체크된 input 배열 반환
