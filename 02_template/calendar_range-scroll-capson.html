input 1개일 경우

inp_single 옵션 true 설정

영역 내 '.cal' 클래스를 가진 input 을 지정

영역 내 특정 클래스를 가진 input 을 지정하고자 할 경우 'inp_single_cls' 옵션 사용

// input 및 레이어 호출영역
<div class="inp-cal range single">
    <input type="text" class="cal" value="" title="기간" readonly/>
    <button type="button" class="open-cal">달력레이어 호출</button>
</div>


// 기간달력 선언
let range_cal_single = new nCalendarRangeScroll({
    area : '.inp-cal.single',
    inp_single : true,
    inp_single_cls : '선택자',
    calTitle : '기간 선택'
});

달력 내 특정일만 활성화

enabled_arr 옵션에 관련 배열 적용 시 배열과 동일한 날짜만 활성화

배열이 변경될 경우 달력변수.enabled_update(배열) 로 업데이트 가능

~ 
// input 및 레이어 호출영역
<div class="inp-cal range arr">
    <input type="text" class="cal start" value="" title="시작일" readonly/><i>~</i>
    <input type="text" class="cal end" value="" title="종료일" readonly/>
    <button type="button" class="open-cal">달력레이어 호출</button>
</div>


// 활성화할 날짜 배열
let test_arr = ['2024-11-08', '2024-11-03', '2024-10-22', '2024-10-16', '2024-10-08'];
// 기간달력 선언
let range_cal_arr = new nCalendarRangeScroll({
    area : '.inp-cal.single',
    calTitle : '기간 선택',
    enabled_arr : test_arr
});

// 활성화 배열 변경 시
range_cal_arr.enabled_update(배열명);

달력 옵션 전체

/**
* area (dom/string) : 달력 연계할 input 을 포함한 영역
* inp_single(boolean) : input 을 1개만 사용할 경우 - true 일 경우 inp_start/inp_end 옵션은 무시됨.
* inp_single_cls (string) : input 을 1개만 사용할 경우 선택할 input class 값 - 미설정 시 'cal' 로 설정
* inp_start (dom) : 시작일 input - 별도 dom 지정 없을 경우 area 내 'start' 클래스를 가진 input 으로 설정
* inp_end (dom) : 시작일 input - 별도 dom 지정 없을 경우 area 내 'end' 클래스를 가진 input 으로 설정
* btn (dom) : 달력 호출버튼 - 별도 지정 없을 경우 'open-cal' 클래스를 가진 버튼으로 설정
* 
* inPage (boolean) : 페이지 내 삽입여부 (기본은 false)
* inTarget (dom/string) : inPage 가 true 일 경우 달력 넣을 영역 dom / 선택자
* calTitle (string) : 달력 제목
* drawLimit (string) : 달력 그리기 제한 연월 (ex : '2024-02')
* beforeLimit (number) : 오늘 이전 몇일까지 선택가능하게 할지 number 값 (ex : 20 - 오늘 기준 20일 전까지만 활성화)
* select_gap (number) : 시작일 - 종료일 gap 제한 (ex: 30 - 시작일과 종료일 차이가 30일 이하일 경우만 선택 가능)
* shot_year (boolean) : 연도 표기를 2자리로 할지 여부 (기본은 false)
* enabled_arr (array) : 활성화할 버튼 배열 (각 배열의 값은 'YYYY-MM-DD' 형식)
* activeConfirm : 컨펌 버튼 클릭 시 실행함수
*/
