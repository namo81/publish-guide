숫자 선택

설정된 범위 내의 숫자를 스크롤로 선택

+ 해당 숫자 클릭 시 직접 입력 가능

input 의 chage 값을 통해 설정값 추출 가능 (스크롤 멈출 경우 input 값 업데이트 및 change 이벤트 발생)

input 에 readonly 속성 있을 경우 직접 수정기능 제한 및 active 콜백으로 현재값 확인 가능

여러개를 조합하여 시분초 등의 구성으로 설정 가능

<div class="num-selector hour">
    <input type="number" name="" class="inp-num" value="0"/>
</div>

 * area : 적용 영역 선택자
 * min : 최소값
 * max : 최대값
 * step : 숫자 단위 (10 일 경우 10,20,30~)
 * num_height : 1칸의 높이 값
 * active : 숫자 선택 시 콜백 함수 (인자로 선택된 숫자값 전달)
            단, input 에 readonly 속성 있을 경우에만 사용 가능

 let num_test = new nNumberSelector({
    area : '.num-selector.test',
    min : 0,
    max : 24,
    num_height : 40
});

조합 예시

timer-set 클래스 내부 시/분/초 구성으로 style 되어있는 예시.

<div class="timer-set">
    <div class="num-selector hour">
        <input type="number" name="" class="inp" value="0"/>
    </div>
    <div class="num-selector min">
        <input type="number" name="" class="inp" value="0"/>
    </div>
    <div class="num-selector second">
        <input type="number" name="" class="inp" value="0"/>
    </div>
</div>
