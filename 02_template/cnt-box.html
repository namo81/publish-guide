레이아웃 구조

레이아웃 구조 : header (id : header) / main (id : content) / footer (id : footer)

body > div (id : wrap) 아래 기본 구조

** 'wrap' 의 경우 생략가능

상단 헤더 및 gnb
중앙 컨텐츠 영역
하단 footer 영역 
<header id="header">
	상단 헤더 및 gnb
</header>
<main id="content">
	중앙 컨텐츠 영역
</main>
<footer id="footer">
	하단 footer 영역
</footer>

컨텐츠 구조 단위

레이아웃 내 컨텐츠 구분 단위 순서 : section > area > wrap > box

각 영역의 경우 위 구분단위 클래스를 접두사로 두며, 이후 언더바( _ ) 로 클래스 추가

해당 영역 내에 다수의 요소가 들어갈 때 '구조 단위' 클래스를 사용하며, 내부 컨텐츠가 단순 텍스트, 이미지 등 최종단계일 경우 사용X

서울특별시

중랑구 상봉동

OOO로 OO길

홍길동

<section class="section_main">
	<div class="area_user-info">
		<div class="wrap_info-address">
			<p class="tx-city">서울특별시</p>
			<div class="box_address-local">
				<p class="tx-add-1">중랑구 상봉동</p>
				<p class="tx-add-2">OOO로 OO길</p>
			</div>
		</div>
		<p class="tx-name">홍길동</p>
	</div>
</section>

반복형 컨텐츠 구분

접두사 'cnt' : '구조 단위' 와 별도로 복잡한 컨텐츠가 반복되어 반복클래스가 필요할 경우

ex) 별도 컴퍼넌트 내 반복 구조 ( depth 구조와 별도로 관리 )

'cnt_' 클래스에 공통 style 을 지정하며, 각 컨텐츠별 별도 style 은 cnt_term 같은 완성된 class 에 지정

<div class="cnt_term">
	<p class="title">1. 타이틀1</p>
	<p class="tx-term">내용1</p>
</div>
<div class="cnt_term">
	<p class="title">2. 타이틀2</p>
	<p class="tx-term">내용2</p>
</div>
<div class="cnt_term">
	<p class="title">3. 타이틀3</p>
	<p class="tx-term">내용3</p>
</div>

*[class*="cnt_"] { display:block; border:1px solid #eee; background:#fff; } // 공통스타일
.cnt_term { font-size:15px; line-height:24px; } // 개별 스타일
