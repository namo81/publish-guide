Input 제어

전체선택 - checkAll

checkAll(allInp, inpName) : 같은 name 을 가진 checkbox 를 전체선택 checkbox 로 제어 (1단계 목록)

  • - allInp : 전체선택 checkbox (선택자 or dom) / inpName : 제어할 checkbox 의 name (없으면 allInp 의 data-name)
  • - 전체선택 checkbox 와 항목이 떨어져 있어도 사용 가능 (ex : 테이블 헤더의 전체선택)
  • - 일부만 선택된 경우 전체선택 checkbox 는 indeterminate(일부 선택) 상태
  • - disabled 항목은 제외 / 상태가 바뀐 항목에 change 이벤트 발생
<input type="checkbox" id="chk-all" class="checkbox" data-name="agree">
<label for="chk-all">전체 동의</label>

<input type="checkbox" id="agree-1" name="agree" class="checkbox"> <label for="agree-1">이용약관 동의</label>
<input type="checkbox" id="agree-2" name="agree" class="checkbox"> <label for="agree-2">개인정보 수집 및 이용 동의</label>

checkAll('#chk-all');			// name 은 data-name 사용
checkAll('#chk-all', 'agree');	// name 직접 지정

다중 depth 전체선택 - checkAllDepth

checkAllDepth(area, selector) : 중첩 목록 구조에서 상위 / 하위 checkbox 상태 연동 (depth 제한 없음)

  • - area : 적용 영역 / selector : 대상 checkbox 선택자 (기본 'input[type=checkbox]')
  • - 구조 : 각 checkbox 는 li 안에 위치하고, 하위 항목은 같은 li 안의 ul 에 배치
  • - 상위 체크 시 하위 전체 체크 / 해제, 하위가 모두 체크되면 상위 체크, 일부만 체크되면 상위는 indeterminate
  • - 기존 dep1 / dep2 / dep3 클래스 구조도 그대로 동작 (클래스는 필수 아님)

※ checkAll 과 분리 유지 : checkAll 은 name 기준(위치 무관), checkAllDepth 는 마크업 구조 기준이라 사용 조건이 다름

<ul class="chk-depth">
	<li>
		<input type="checkbox" id="dep-1"> <label for="dep-1">전체 메뉴</label>
		<ul>
			<li>
				<input type="checkbox" id="dep-1-1"> <label for="dep-1-1">게시판</label>
				<ul>
					<li><input type="checkbox" id="dep-1-1-1"> <label for="dep-1-1-1">공지사항</label></li>
					<li><input type="checkbox" id="dep-1-1-2"> <label for="dep-1-1-2">자유게시판</label></li>
				</ul>
			</li>
		</ul>
	</li>
</ul>

checkAllDepth('.chk-depth');

radio 선택에 따른 영역 표시 - radioSelectTg

radioSelectTg(area, name, func) : 선택된 radio 의 data-target 영역만 표시

  • - data-target : 표시할 영역의 클래스명 (점 없이) - 여러 radio 가 같은 영역 지정 가능 / 없으면 모든 영역 숨김
  • - 숨김 영역이 fieldset 이면 disabled 처리 (form 전송 제외)
  • - 선택된 radio 가 없으면 초기에 모든 영역 숨김 / 방향키 선택에도 동작
  • - func(input, target) : 선택 변경 시 콜백
수령 방법
배송지
방문 매장 
<input type="radio" name="receive" id="receive-1" data-target="tg-delivery" checked> <label for="receive-1">택배</label>
<input type="radio" name="receive" id="receive-2" data-target="tg-visit"> <label for="receive-2">방문 수령</label>
<input type="radio" name="receive" id="receive-3"> <label for="receive-3">미정</label>

<fieldset class="tg-delivery"> ... </fieldset>
<fieldset class="tg-visit"> ... </fieldset>

radioSelectTg('.radio-tg-area', 'receive', function(inp, tg){
	console.log(inp.id, tg);
});

checkbox 선택에 따른 영역 활성화 - chk_tgl_ctrl

chk_tgl_ctrl(area, inp, target, func) : checkbox 해제 시 target 영역에 inert 속성 부여 (클릭 / 포커스 / 스크린리더 접근 차단)

  • - area : 검색 범위 / inp : 제어용 checkbox / target : 비활성화할 영역 선택자 / func(비활성화 여부) : 콜백
  • - 비활성화 스타일은 css 의 [inert] 또는 target 에 추가되는 'inert' 클래스로 지정
  • - 제어용 checkbox 가 target 안에 있으면 checkbox(label 포함)를 제외한 나머지 요소에만 inert 적용
  • - ※ inert 는 disabled 와 달리 form 전송에서 제외되지 않음 - 전송 제외가 필요하면 콜백에서 처리
<input type="checkbox" id="use-alarm"> <label for="use-alarm">알림 사용</label>
<div class="alarm-box">
	<select id="alarm-time">...</select>
	<button type="button" class="btn small">테스트 발송</button>
</div>

.alarm-box[inert] { opacity:.4; }

chk_tgl_ctrl('.chk-tgl-area', '#use-alarm', '.alarm-box', function(off){
	console.log('비활성화 : ' + off);
});
