기본 - placeholder

placeholder 같은 효과 - 기본 상태 color 적용

selece 에 required 속성 필요 / select:invalid 속성으로 값이 없는 상태의 color 값 설정

option 에 별도 color 적용 필요

<select name="" title="" required>
	<option value="" hidden>선택해주세요.</option>
	<option value="">직접 선택</option>
	<option value="">nate.com</option>
	<option value="">daum.net</option>
</select>


select:invalid { color:#aaa; }
option { color:#000 }
