글자 수 카운트

nTextCount(area) : area 안의 input / textarea 입력 글자 수를 '.inp-count .now' 에 표시

maxlength 가 있으면 '.inp-count .max' 에 최대 글자 수 표시 및 초과분 제거 (한글 조합 중에는 제거하지 않음)

카운트 영역은 input 의 aria-describedby 로 자동 연결 (포커스 시 스크린리더가 글자 수 안내를 함께 읽음)

0 / 자

</div>

	<option value="">nate.com</option>
	<option value="">daum.net</option>

File

label 값 필수.

최소 사이즈 200px

  • - 선택된 파일명 표시 (경로 'C:\fakepath\' 제외) / multiple 일 경우 'OO 외 n개'
  • - input 의 placeholder 를 파일명 영역 placeholder 로 사용
  • - '첨부파일 제거' 버튼 : 선택 파일 삭제 후 input / change 이벤트 발생
  • - 외부 호출 : 선언변수.inpReset() (파일 삭제) / 선언변수.inpFileNameShow('파일명') (기존 첨부파일명 표시)
