모바일용 Select v2.0.0

개요

select 를 버튼으로 대체하고, 버튼 클릭 시 화면 하단에 option 과 연동된 목록을 표출

v1 의 nSelectDrag(클릭+드래그) / nSelect(클릭) 를 nSelectMobile 하나로 통합 - drag 옵션으로 드래그 선택 on/off

  • - drag : false (기본) - 일반 목록 / 항목 클릭 시 바로 선택
  • - drag : true - 휠 형태 목록 / 드래그(터치 스크롤) 후 '확인' 버튼으로 선택, 항목 클릭 시 바로 선택

hidden option 은 목록에서 제외 / disabled option 은 선택 불가 / select 에 readonly · disabled 속성이 있으면 열리지 않음

common.js 불필요 (v2.0.0 부터 의존 파일 없음)

예시

변경 내역 : -

html

select 를 감싼 영역(area)을 지정 / label 이 연결되어 있으면 버튼에 "label + 선택값" 으로 자동 연결

<label for="sel-click">클릭 선택</label>
<div class="n-select sel-click">
	<select name="sel-click" id="sel-click">
		<option value="" hidden>선택해주세요</option>
		<option value="1">string 1</option>
		<option value="2">string 2</option>
		<option value="3" disabled>string 3 (disabled)</option>
	</select>
</div>

script

option 항목

  • - area : select 를 감싼 영역 ( type : string / dom ) 필수
  • - title : 목록 상단 타이틀 ( type : string ) - 없으면 label 텍스트를 모달 이름(aria-label)으로 사용
  • - drag : 드래그 선택 사용 ( type : boolean ) - 기본 false
  • - optHeight : (drag) 항목 1개 높이 px ( type : number ) - 기본 40
  • - btnCls : select 대신 표시되는 버튼 클래스 - 기본 'btn-sel'
  • - modalCls : 모달에 추가할 클래스
  • - btnConfirmTx / btnCloseTx : 확인 / 닫기 버튼 텍스트 - 기본 '확인' / '닫기'
  • - activeChange : 값 변경 후 콜백 ( function(select, value, index) )

메서드 : open() / close() / update() / set_disabled() / set_enabled() / destroy()

스크립트로 select 값을 변경한 경우 update() 호출 / 값이 바뀌었을 때만 select 에 change 이벤트 발생

// 클릭 선택
let selClick = new nSelectMobile({
	area : '.n-select.sel-click',
	title : '항목 선택'
});

// 드래그 선택
let selDrag = new nSelectMobile({
	area : '.n-select.sel-drag',
	title : '숫자 선택',
	drag : true,
	optHeight : 40,
	activeChange : function(select, value, index){
		console.log(select.id, value, index);
	}
});

// 스크립트로 값 변경 후 반영
document.querySelector('#sel-drag').value = '2';
selDrag.update();

웹접근성

  • - 버튼 : aria-haspopup="dialog" / aria-expanded 자동 설정
  • - 모달 : role="dialog" / aria-modal="true" / 타이틀(aria-labelledby) 또는 label 텍스트(aria-label) 연결
  • - 목록 : ul role="listbox" / 항목 button role="option" + aria-selected
  • - 열기 시 타이틀(없으면 선택 항목)로 포커스 이동, 모달 외 영역 inert 처리
  • - ESC / 닫기 버튼 / 선택 후 select 버튼으로 포커스 복귀
